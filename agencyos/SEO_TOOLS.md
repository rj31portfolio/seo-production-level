## Shared workflow and limits

Open /seo/tools, select a permitted project, submit input, inspect the actual run status/findings, export CSV/XLSX, generate project tasks for actionable failed checks or save a report snapshot. Reports offer escaped HTML and queued private PDF. Keyword results can be saved to the project keyword list. Project-less analyses are available only to roles with clients.view. There is no public/client sharing endpoint yet.

Every run records tenant/user, optional client/project/website, input, source, status, timing, summary and results. Role, project, global availability, platform tool plan, quota and client service status constrain admission. History survives client expiry according to existing read policies. Archived runs retain records.

Defaults: 30 crawl pages, depth 3, 1-second delay, 15-second request timeout, 2 MB response cap, 5 redirects, 6 submissions/minute. Platform/plan limits can be stricter. Keyword and table imports are capped at 500 rows and 256 KB; workbooks have expanded-size safety limits. Supplied content is capped at 100,000 characters. AI request sizes and attempt/token limits are configurable. Unknown metrics stay unavailable.
